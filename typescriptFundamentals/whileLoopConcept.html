The While Loop:
Control the Cycle

An entry-controlled loop that repeats a block of code as long as a specified condition evaluates to true.

01

The Basic Mechanism

The while loop is the simplest form of repetition. It checks the condition before executing the body.

  • Initialization: A variable is set before the loop starts.
  • Condition: A boolean expression checked at the start of every iteration.
  • Update: The variable is modified inside the loop to eventually make the condition false.
example.ts // Simple count from 1 to 5
let num: number = 1;

while (num <= 5) {
  console.log(num);
  num++; // Incrementing the counter
}
02

Logic & Filtering

Loops are powerful when combined with conditional statements. This allows you to process only specific data points.

In this example, we use the modulo operator (%) to identify even numbers.

  • i % 2 === 0: True if number is even.
  • i % 2 !== 0: True if number is odd.
filter.ts // Print even numbers from 1 to 10
let i: number = 1;

while (i <= 10) {
  if (i % 2 === 0) {
    console.log(i);
  }
  i++; // Always increment, regardless of if-block
}
03

Directional Control

By changing the comparison operator and the update expression, you can reverse the flow of the loop.

To count downwards, use >= (greater than or equal) and -- (decrement).

descend.ts // Countdown from 10 to 1
let i: number = 10;

while (i >= 1) {
  console.log(i);
  i--; // Subtract 1 each time
}
04

The Danger Zone

⚠

The Infinite Loop

An infinite loop occurs when the condition never becomes false. This will freeze your application or crash the browser tab.

Common causes of infinite loops:

  • Forgetting the update expression (i++).
  • Updating the variable in the wrong direction (e.g., i-- when you need i++).
  • A condition that is mathematically impossible to fail.
danger.ts let i: number = 1;

while (i <= 5) {
  console.log("I will never stop!");
  // ERROR: Missing i++ here!
}
